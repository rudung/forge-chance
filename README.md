# Forge Chance v1.1.2

오프라인 세로형 강화/방치 게임입니다.

## v1.1.2
- 파괴 확률 완화: 기존 파괴확률 ÷ 2 - 1%p
- 줄어든 파괴 확률은 유지 확률로 이동
- 성공률과 하락률은 유지
- 파괴 확률
  - +9→+10: 1.5%
  - +10→+11: 2.0%
  - +11→+12: 2.5%
  - +12→+13: 3.0%
  - +13→+14: 3.5%
  - +14→+15: 4.0%
  - +15→+16: 4.5%
  - +16→+17: 5.0%
  - +17→+18: 5.5%
  - +18→+19: 6.0%
  - +19→+20: 6.5%
- 강화 시간
  - +0~+10: 즉시
  - +11~+14: 0.3초
  - +15~+20: 0.5초
- 결과 OK 버튼은 강화하기 버튼과 동일 좌표/크기
- 같은 위치 반복 터치로 강화 → OK → 강화 진행 가능
- 결과창 표시 중에도 G/s 수입 계속 누적

# Forge Chance v1.1

오프라인 세로형 강화/방치 게임입니다.

## v1.1
- 강화 연출 시간 단축
  - +0~+5: 0.5초
  - +6~+10: 1.5초
  - +11~+15: 2.5초
  - +16~+20: 3.5초
- 파괴 후 저단계 재강화 구간의 반복 피로도 완화
- 강화 결과창은 자동으로 닫히지 않고 계속 표시
- 결과창 OK 버튼을 누르면 즉시 닫히고 다음 강화 가능
- 결과창이 떠 있는 동안에도 G/s 수입은 계속 누적

## v1.0
- 4직업 × 7부위 = 28개 고정 장비
- 한 화면에서 직업/장비 선택과 강화 수행
- 판매/가방/장비교체 제거
- 초당 골드(G/s) 실시간 수입 + 최대 12시간 오프라인 수입
- +0~+20 확정 강화 확률표 적용
- 파괴 시 같은 슬롯 +0 초기화
- 일반 강화 100회마다 행운의 동전 1개, 최대 1개
- 행운의 동전: 앞면 50% 무조건 +1 / 뒷면 50% 무조건 -1
- 성공/유지/하락/파괴/동전 전용 시각 연출
- 파괴 시에만 화면 흔들림
- 사운드/진동/BGM 없음
- 업적 별도 화면

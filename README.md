# Forge Chance v1.1.1

오프라인 세로형 강화/방치 게임입니다.

## v1.1.1 Hotfix
- 강화 연출 시간 재조정
  - +0~+5: 즉시
  - +6~+10: 0.2초
  - +11~+15: 0.5초
  - +16~+20: 1.0초
- 강화 결과창 OK 버튼을 강화하기 버튼과 완전히 같은 좌표/크기로 배치
- 같은 위치를 반복 터치하면 강화 → OK → 강화 → OK 순서로 진행 가능
- 결과창이 떠 있는 동안에도 G/s 수입은 계속 누적

## v1.1
- 강화 결과창 자동 종료 제거
- OK 버튼으로 결과창 닫기
- 단계별 강화 시간 단축

- 파괴 시 같은 슬롯 +0 초기화
